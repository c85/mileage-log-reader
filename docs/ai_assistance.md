# AI assistance disclosure

OpenAI Codex assisted with repository implementation, code scaffolding,
review of the supplied project brief, and draft documentation. This included
manually transcribing fictional development-form labels,
implementing printed-template and box alignment with OpenCV, small-artifact
cleanup, review checks, regression tests and evaluation reports. The existing
EMNIST classifier remains the reader; no pretrained OCR or LLM reads images
in the application. The project team is responsible for reviewing and
understanding the submitted code and
for explaining the model, pipeline, results, and limitations during the
demonstration.
