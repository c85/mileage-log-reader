# Handwritten development forms

Place the three new hand-filled forms in this folder as PNG files named
`form_01.png`, `form_02.png` and `form_03.png`.

These forms are for development and reader improvement. Keep them separate from
`../team_filled_forms/`, which is the held-out evaluation set. Use fictional
values and share full-page, unmodified scans or photos so the original writing
can be read. Ground-truth labels can be added after the images arrive.
